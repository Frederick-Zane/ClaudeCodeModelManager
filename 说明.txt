ccm - Claude Code Model Manager

用法：

  ccm list
    列出所有模型，当前模型标 *

  ccm current
    显示当前模型和 provider

  ccm use <model>
    切换模型，直接修改 Claude Code 配置

  ccm add-model <name> <provider> <model_id>
    添加模型。provider 必须已存在。

  ccm add-provider <name> <base_url> <auth_token>
    添加 provider。

  ccm tui
    交互式模型切换器。
    上下键选择，回车切换（不退出），q 退出。
    a: 添加模型  p: 添加 provider  r: 删除选中模型

  ccm remove <name>
    删除模型或 provider。自动判断类型。
    如果 provider 被模型引用，拒绝删除。
    如果删除的是当前模型，自动清空 current。

示例：

  ccm add-provider openrouter https://openrouter.ai/api/v1 sk-xxx
  ccm add-model r1 openrouter deepseek/deepseek-r1
  ccm use r1
  ccm list
  ccm current
  ccm remove r1

文件修改对照：

  ~/.config/ccm/config.toml
    ccm use         更新 [current]
    ccm add-model   写入 [models.<name>]
    ccm add-provider 写入 [providers.<name>]
    ccm remove      删除对应条目；若删当前模型则清空 [current]
    ccm tui         同 use / add-model / add-provider / remove（按操作对应）

  ~/.claude/settings.json
    ccm use         修改 env 块（AUTH_TOKEN / BASE_URL / MODEL）
                    修改前自动备份到 ~/.config/ccm/backups/
    ccm tui         同 ccm use（回车确认后）

  ~/.config/ccm/backups/
    ccm use         备份 settings.json，保留最近 20 份
